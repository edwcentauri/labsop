# 说明书收录与关联规范

## 适用范围

本规范适用于首页“说明书”栏目、说明书 PDF 预览与下载页，以及 SOP 页面中的关联说明书入口。产品说明书、仪器操作手册、使用方法和与实验直接相关的合成报告均可收录。

## 1. 来源与内容边界

- 只收录用户明确提供或批准的原始 PDF，不使用演示文件、占位文件或网络搜索结果代替。
- 默认不读取、提取或总结 PDF 正文。标题、简写名、文档类型和分类标签仅依据原文件名及用户明确提供的信息建立。
- 不从文件名推断实验步骤、参数、安全警告、版本生效状态或适用范围，也不得把说明书元数据写入受控 SOP 内容。
- 简写标题可采用厂商、商品名、型号或品种等易识别形式；原始文件名必须保留在 `fileName` 中，供下载时使用。

## 2. 文件与元数据

- 原始文件存放在 `public/pdfs/manuals/`，不得覆盖同名既有文件。文件更新应新增可区分的文件名和条目，并由用户确认旧文件是否保留。
- 元数据统一维护在 `src/manuals.ts`，每个条目必须包含稳定且唯一的 `id`、简写标题、文档类型、分类标签、原始文件名、站内路径和关联 SOP ID。
- `pdfPath` 使用相对于 `public/` 的路径；页面必须通过 `import.meta.env.BASE_URL` 构造资源地址，以兼容 `/labsop/` 部署基础路径。
- 标题、`fileName`、`pdfPath` 和实际文件必须一一对应。下载时保留原始文件名。

## 3. 分类标签

- 一个条目可以有多个标签。标签分为文档对象或实验环节，例如“试剂”“仪器”“RNA 提取”“qPCR”“移液枪”“引物”。
- 反转录试剂盒和 RNA 提取试剂盒同时标记“试剂”“RNA 提取”；SYBR 相关试剂同时标记“试剂”“qPCR”；移液器操作手册同时标记“仪器”“移液枪”。
- 引物使用方法及引物合成报告统一标记“引物”，不标记“试剂”。
- 新标签应能服务于多份文档或明确的检索需求，避免仅为单个文件创建同义或过细标签。

## 4. 页面与 SOP 关联

- 首页“说明书”必须独立于“在线工具”展示，并支持按标题、文档类型和全部标签搜索，以及按单个标签筛选。
- 每份说明书均提供独立站内路由，复用站内 PDF 阅读器，并提供原文件下载。
- `relatedSopIds` 是说明书与 SOP 的唯一关联来源。SOP 页面只展示明确关联到自身 ID 的说明书，不根据标签自动推断关联关系。
- 说明书入口是参考资料链接，不改变 SOP 的版本、有效状态、受控步骤或计算逻辑。

## 5. 移动端、主题与无障碍

- 卡片、标签筛选、预览工具栏和下载入口必须适配窄屏、浅色与深色主题。
- 使用语义化链接进入说明书详情页；图标不得成为唯一标签，筛选控件应提供可理解的文字与当前状态。
- 文件无法预览时仍需保留下载入口，并显示明确错误提示。

## 人工验收清单

项目约定由人类维护者执行测试与验收。维护者应至少确认：

- 六项元数据、简写标题、标签、关联 SOP、原始文件名和实际 PDF 一致。
- 首页说明书搜索、多标签筛选、详情路由、PDF 翻页缩放及下载可用。
- RNA + qPCR SOP 页面能访问全部相关说明书，且不改变原 SOP 内容与计算结果。
- `/labsop/` 基础路径、手机窄屏、桌面宽屏、浅色与深色主题显示正常。
