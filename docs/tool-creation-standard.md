# 在线工具创建规范

## 基准实现

`组织提 RNA（柱提法）+ qPCR` 是本项目在线工具的基准实现。新增或重构工具时，应复用它的工程边界、受控内容管理方式和交互质量标准，但只实现新 SOP 实际需要的功能，不机械复制 qPCR 专属页面或计算。

基准文件如下：

- `src/RnaQpcrTool.tsx`：页面结构、强类型会话状态、分步交互、输入反馈和本地保存。
- `src/rnaQpcrData.ts`：受控 SOP 文本、警告、分支步骤、PDF 文件名、路径、版本和版本更新说明。
- `src/VersionHistoryDialog.tsx`：SOP 页版本入口与版本更新说明悬浮窗。
- `src/calculations.ts`：与 React 解耦的计算、校验、布局和汇总纯函数。
- `src/calculations.test.ts`：正常路径、边界值、无效输入和跨步骤联动测试。
- `src/data.ts`、`src/App.tsx`：首页清单、工具路由和 PDF 路由接入。
- `src/styles.css`：移动端优先的响应式布局、浅色/深色主题和可交互状态。

## 强制要求

### 1. 先确认受控来源

- 实验步骤、参数、警告、版本号和生效日期只能来自用户提供或明确批准的来源。
- 标题、版本、PDF 文件名、站内路径和下载文件名必须一致；使用 `import.meta.env.BASE_URL` 构造静态资源地址，兼容 `/labsop/` 部署基础路径。
- 每个新发布版本都必须记录版本号、发布或生效日期和简明更新说明；仅根据已批准来源建立记录，不为来源不足的历史版本补写或臆造说明。
- 当前 SOP 的生效日期永远等于最新版本的发布日期；新版本发布时必须同步更新两者。
- 未取得批准来源的工具不得以占位卡片、演示 PDF 或虚构参数进入首页可用清单。

### 2. 分离内容、计算与界面

- 受控 SOP 内容和 PDF 元数据放入独立的强类型数据模块，参照 `src/rnaQpcrData.ts`。
- 版本更新说明与 SOP 元数据同源管理，页面展示时按 ISO 日期从新到旧排列，不要在组件中散落写死的版本文案。
- 公式、单位换算、舍入、校验、布局生成和汇总逻辑写成 `src/calculations.ts` 中的小型纯函数；React 组件只负责采集输入、组合状态和呈现结果。
- 每个新增或修改的计算规则都必须在 `src/calculations.test.ts` 中覆盖正常路径、边界值和无效输入。不得使用 `any` 绕过类型设计。

### 3. 交互必须覆盖完整实验工作流

- 根据 SOP 的实际依赖组织流程；复杂工具优先采用“初始化 → 互动 SOP → 领域规划/结果”的渐进结构。
- 上游输入变化必须可靠联动下游结果；不能让旧的板图、分装量、浓度或完成状态伪装成当前批次结果。
- 对缺失、非数值、超范围、不可能配制和容量溢出等情况提供就地、可执行的错误提示；不要只隐藏结果。
- 多步骤内容应显示当前位置、完成状态、返回路径和下一步动作。受控警告在相关步骤旁展示，不得弱化或省略。

### 4. 会话状态应安全且可恢复

- 为会话定义明确的 TypeScript 类型和集中默认值。
- 需要保存草稿时，使用工具专属、带版本号的 `localStorage` 键；读取旧数据必须逐字段校验并在解析失败时安全回退。
- 提供明确的重置操作。敏感实验数据不得在未获授权的情况下上传或接入外部服务。

### 5. 保持移动端、主题与无障碍完整

- 从窄屏开始设计导航、表单、表格、板图、分页和操作按钮；宽屏只做增强。
- 新样式必须同时考虑浅色、深色和 `prefers-reduced-motion`，并保持与基准工具一致的视觉层级。
- 所有表单控件、图标按钮、标签页和状态提示应有可理解的标签，支持键盘操作，并使用正确的按钮类型和语义结构。
- SOP 页的版本显示必须是可操作入口，打开支持 Escape 关闭、焦点恢复、浅色/深色主题和窄屏的悬浮窗，并按日期从新到旧展示记录。

### 6. 完整接入项目

- 仅在工具达到可用状态后向 `src/data.ts` 添加条目，并在 `src/App.tsx` 添加明确路由。
- 有 PDF 时同时提供站内查看与原文件下载；没有 PDF 时不要伪造入口或版本。
- 发布新 SOP 版本时同步新增公告栏通知，公告中的标题、版本、日期和更新摘要必须与 SOP 页及版本更新说明一致。
- 只添加工具实际需要的依赖和样式，不保留占位卡片、废弃路由、演示文件、不可达组件或孤立计算函数。

## 提交前人工验收清单

项目约定由人类维护者执行测试与验收。维护者应至少确认：

- 受控来源、标题、版本、日期、PDF 文件名、页面内容、版本更新说明和公告一致。
- 全部公式、单位、舍入、边界值与批准来源一致，自动化测试覆盖关键分支。
- 刷新后草稿恢复正确，重置能清除本工具状态，上游修改不会留下过期结果。
- 手机窄屏、桌面宽屏、浅色、深色、键盘操作和减少动画模式均可用。
- 首页搜索与分类、工具路由、PDF 查看、下载和 `/labsop/` 基础路径均正常。
- SOP 页和 PDF 页的版本入口均能打开悬浮窗，版本记录按日期从新到旧显示，且公告可正常查看。
